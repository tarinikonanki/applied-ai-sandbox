## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md | Claude Code | Claude reads everything so having info will help it run better / help the project. |

| Review a teammate's PR for security issues | Claude Code | Because it accesses a lot of information about the project, it can understand if the PR is needed. |
| Cross-file refactor with consistent renames | Cursor | It's good at editing quickly. |
| Learning a new library's API | Claude/ChatGPT| It has access to a lot of information |
